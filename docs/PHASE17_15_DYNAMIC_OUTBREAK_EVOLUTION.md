# PHASE 17.15 — DYNAMIC OUTBREAK EVOLUTION

## Timeline
Day 1–3: Localized Outbreak
Day 4–7: Infected Migration
Day 8–14: District Collapse
Day 15+: Horde Conditions

## Persistent evolution
Each expedition advances the outbreak timeline. Stage transitions increase Safehouse threat and alter outbreak pressure.

## Horde events
During Horde Conditions, expeditions can trigger migrating horde events that increase Safehouse threat.

## Runtime
The Safehouse displays current outbreak day, stage, description, pressure and next escalation threshold.

## API
`CheegunOutbreakEvolution.advanceDay()`
`CheegunOutbreakEvolution.stage()`
`CheegunOutbreakEvolution.districtRisk()`
`CheegunOutbreakEvolution.hordeCheck()`
`CheegunOutbreakEvolution.status()`
