# PHASE 17.22 — SURVIVOR TRAITS, PERSONAL STORIES & LEGACY

Each survivor has persistent traits, a personal story, loyalty, mission history, and heroic-act tracking.

## Traits
Brave, Resourceful, Compassionate, Disciplined, Haunted, Leader.

## Legacy
The memorial system can permanently record a survivor's role, story, traits, mission history, heroic acts, cause, and location.

## API
CheegunSurvivorLegacy.profile(id)
CheegunSurvivorLegacy.modifier(ids)
CheegunSurvivorLegacy.missionOutcome(mission,success)
CheegunSurvivorLegacy.recordDeath(id,details)
CheegunSurvivorLegacy.summary()
