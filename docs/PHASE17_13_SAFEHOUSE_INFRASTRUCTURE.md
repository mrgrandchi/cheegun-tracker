# PHASE 17.13 — SAFEHOUSE CONSTRUCTION & INFRASTRUCTURE

## Buildings
- Medical Bay
- Workshop
- Armory
- Storage Depot
- Radio Room
- Survivor Quarters
- Defensive Wall

## Progression
Each building upgrades from Level 0 to Level 3. Upgrades require credits and, where appropriate, assigned survivor staff.

## Integrated benefits
- Medical Bay reduces treatment costs
- Workshop reduces gear repair costs
- Storage Depot provides storage expansion value
- Survivor Quarters expands population capacity
- Armory, Radio and Defensive Wall provide progression values for expedition/security systems
