# PHASE 17.23 — SURVIVOR STORY EVENTS & LEADERSHIP DECISIONS

## Dynamic story events
Leadership events emerge from the survivor community and present Craig with persistent choices.

Initial events:
- Loyalty Divided
- A Voice on the Radio
- Dangerous Volunteer
- Natural Leader

## Consequences
Choices can alter survivor loyalty, community morale, trust and survivor relationships. A leadership promotion can permanently designate a survivor as a lieutenant.

## Runtime
Events can generate during Safehouse checks or world progression. Only one active leadership event is held at a time.

## API
`CheegunStoryEvents.generate(force)`
`CheegunStoryEvents.resolve(choiceId)`
`CheegunStoryEvents.tick()`
`CheegunStoryEvents.summary()`
