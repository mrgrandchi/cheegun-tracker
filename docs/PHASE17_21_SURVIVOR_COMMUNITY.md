# PHASE 17.21 — SURVIVOR RELATIONSHIPS, MORALE & COMMUNITY

## Persistent community state
- Settlement morale
- Community trust
- Survivor fatigue
- Mission injuries
- Pair relationships
- Conflicts and community events

## Mission integration
Successful and failed autonomous missions now affect team fatigue, relationships and settlement morale. Failed missions can also create injuries.

## Community actions
- Community Meal
- Memorial Night
- Survivor Conflict
- Small Victory

## Leadership
Combined morale and trust generate a leadership effect value for future system integration.

## API
`CheegunSurvivorCommunity.summary()`
`CheegunSurvivorCommunity.communityEvent(id)`
`CheegunSurvivorCommunity.missionOutcome(mission,success)`
`CheegunSurvivorCommunity.rest(survivorId)`
`CheegunSurvivorCommunity.relationship(a,b)`
